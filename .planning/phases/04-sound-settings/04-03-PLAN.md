# Plan 04-03: Wire SoundSettingsOverlay into App.vue + Human Verify

## Objective
Import SoundSettingsOverlay, wire it into App.vue so the mute button in ScoreHeader opens it, thread all props/emits, and do a final end-to-end human verification.

## Context Files
- `src/App.vue`
- `src/components/ScoreHeader.vue`
- `src/components/SoundSettingsOverlay.vue`
- `src/composables/useSound.js`

## Tasks

### Task 1: Import and register SoundSettingsOverlay in App.vue
- Add `import SoundSettingsOverlay from './components/SoundSettingsOverlay.vue'` to App.vue
- Add `const showSoundSettings = ref(false)` reactive state
- Destructure `volume` and `setVolume` from `useSound()` (already exported after plan 04-01)
- Add handler functions:
  ```js
  function onOpenSoundSettings() { showSoundSettings.value = true }
  function onCloseSoundSettings() { showSoundSettings.value = false }
  function onSetVolume(v) { setVolume(v) }
  ```

**Verify:** App.vue compiles without errors.

### Task 2: Update ScoreHeader to emit open-sound-settings
- Change the mute button in `ScoreHeader.vue` so that clicking it emits `'open-sound-settings'` instead of `'toggle-mute'`
- Keep `'toggle-mute'` in defineEmits (still needed by the overlay itself)
- Add `'open-sound-settings'` to defineEmits

In App.vue template, change `@toggle-mute="toggleMute"` on ScoreHeader to `@toggle-mute="toggleMute" @open-sound-settings="onOpenSoundSettings"`.

**Verify:** Clicking the 🔊 button opens the overlay; clicking 🔊/🔇 inside the overlay toggles mute.

### Task 3: Add SoundSettingsOverlay to App.vue template
Add after the ShopOverlay block:
```html
<!-- Sound Settings Overlay -->
<Transition name="fade">
  <SoundSettingsOverlay
    v-if="showSoundSettings"
    :show="showSoundSettings"
    :is-muted="isMuted"
    :volume="volume"
    @close="onCloseSoundSettings"
    @toggle-mute="toggleMute"
    @set-volume="onSetVolume"
  />
</Transition>
```

**Verify:** Overlay appears, volume slider moves and updates audio, mute toggle works inside overlay.

### Task 4: CHECKPOINT — Human Verify
**Type:** checkpoint:human-verify

- `useSound.js` extended with master GainNode, volume ref (0–1), setVolume(), localStorage persistence for both mute and volume
