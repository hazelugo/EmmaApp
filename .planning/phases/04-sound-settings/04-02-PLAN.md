# Plan 04-02: SoundSettingsOverlay.vue Component

## Objective
Create `SoundSettingsOverlay.vue` — a modal overlay with a styled volume slider and a mute toggle button. Pure presentation component; receives props, emits events. Follows the established overlay pattern (v-if + Transition, scoped CSS, no router).

## Context Files
- `src/components/ShopOverlay.vue` (pattern reference)
- `src/style.css`

## Tasks

### Task 1: Create SoundSettingsOverlay.vue
Create `src/components/SoundSettingsOverlay.vue` with:

**Props:**
- `show` Boolean — controls visibility
- `isMuted` Boolean
- `volume` Number (0–1)

**Emits:**
- `close` — user tapped backdrop or X button
- `toggle-mute` — user tapped mute button
- `set-volume(value: Number)` — user moved slider (emit the new 0–1 value)

**Template structure:**
```
<Transition name="settings-fade">
  <div v-if="show" class="overlay-backdrop" @click.self="$emit('close')">
    <div class="settings-panel">
      <header> <h2>Sound Settings</h2> <button @click="close">✕</button> </header>

      <!-- Mute Toggle row -->
      <div class="setting-row">
        <label>Sound</label>
        <button @click="$emit('toggle-mute')">{{ isMuted ? '🔇 Muted' : '🔊 On' }}</button>
      </div>

      <!-- Volume Slider row (disabled when muted) -->
      <div class="setting-row">
        <label>Volume</label>
        <input type="range" min="0" max="1" step="0.05"
               :value="volume"
               :disabled="isMuted"
               @input="$emit('set-volume', Number($event.target.value))" />
        <span>{{ Math.round(volume * 100) }}%</span>
      </div>
    </div>
  </div>
</Transition>
```

**Scoped CSS:**
- `.overlay-backdrop`: fixed inset-0, z-[300], dark semi-transparent bg, flex center
- `.settings-panel`: Nintendo-style block border, mario-red background, rounded-2xl, min-w 280px, padding, gap
- `settings-fade` transition: opacity 0.25s + translateY(−16px → 0)
- Volume slider: styled track and thumb in Mario red/gold palette; thumb scales on hover
- Mute button: btn-press style (matches existing buttons), distinct active/inactive states

**Verify:** Component file exists and imports without error.
