# Plan 04-01: Refactor useSound.js — Master GainNode + Volume + Persistence

## Objective
Add a master GainNode to useSound.js so that volume can be controlled independently of mute. Persist both `isMuted` and `volume` to localStorage. Expose a `volume` ref and a `setVolume(v)` function. Keep full backward compatibility with existing callers.

## Context Files
- `src/composables/useSound.js`

## Tasks

### Task 1: Add master GainNode + volume ref to useSound.js
- Add `const volume = ref(parseFloat(localStorage.getItem('emma-volume') ?? '0.7'))`
- Add module-level `let masterGain = null`
- Update `getContext()` to create and connect masterGain → ctx.destination on first call, and set its gain from the volume ref
- Change all `gain.connect(ctx.destination)` calls to `gain.connect(masterGain)` so all SFX flow through the master gain
- Update `playTone()` to route through masterGain

**Verify:** `masterGain` is created once and all tone connections go through it.

### Task 2: Add setVolume() and persist both settings
- Add `function setVolume(v)` that clamps v to [0, 1], sets `volume.value = v`, sets `masterGain.gain.value = v` (if masterGain exists), and persists `localStorage.setItem('emma-volume', v)`
- Update `toggleMute()` to also call `localStorage.setItem('emma-mute', isMuted.value)` after toggling
- On module load, read `isMuted.value = localStorage.getItem('emma-mute') === 'true'`
- Update BGM Audio element volume: in `playThemeMusic()` set `currentBgmAudio.volume = volume.value`; in `setVolume()` also update `currentBgmAudio.volume` if it exists

**Verify:** Calling `setVolume(0.5)` updates the ref and localStorage. `isMuted` loads from localStorage on page refresh.

### Task 3: Export volume and setVolume from useSound()
- Add `volume` and `setVolume` to the return object of `useSound()`

**Verify:** `const { volume, setVolume } = useSound()` destructures without error.

## Success Criteria
- `useSound()` returns `{ isMuted, volume, toggleMute, setVolume, playCorrect, playWrong, playTap, playStreak, playLevelUp, playThemeMusic, stopThemeMusic }`
- All SFX route through masterGain
- Both mute and volume persist across page refresh
- `npm run build` passes with no errors
